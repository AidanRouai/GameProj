# Vampire Survivors Clone

A 2D survival action game inspired by Vampire Survivors, built with Unity.

## Description

This game is a student project that recreates core mechanics from the popular game Vampire Survivors. Players survive waves of enemies while automatically attacking and collecting power-ups to become stronger.

## Features

- Top-down 2D gameplay
- Auto-attacking system
- Enemy wave spawning
- Character progression and leveling
- Power-up collection system
- Multiple weapons and abilities

## Prerequisites

- Unity 2022.3 LTS or later
- Visual Studio 2019/2022 or VS Code with C# extension

## Installation

1. Clone the repository
```bash
git clone github.com/AidanRouai/GameProj
```
2. Open the project in Unity Hub
3. Build project 

## Controls

- WASD or Arrow Keys - Move character
- ESC - Pause game
- Space - Select upgrades (when leveling up)
